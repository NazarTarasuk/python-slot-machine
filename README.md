# 🎰 Slot Machine Simulator

Цей проект — симулятор ігрового автомата на Python. Він був створений як навчальний проект для відпрацювання навичок модульного програмування, об'єктно-орієнтованого підходу (OOP) та роботи з файловою системою.

## 🚀 Основні можливості
* **Модульна архітектура:** Логіка гри, збереження даних та інтерфейс розділені на окремі файли для легкого обслуговування.
* **Data Persistence:** Баланс гравця автоматично зберігається у файл `save.txt`, тому прогрес не втрачається після закриття гри.
* **Чистий код:** Код написаний з використанням анотацій типів (Type Hinting) та структурований згідно з принципами Clean Code.
* **Захист від помилок:** Програма коректно обробляє введення користувача та помилки при роботі з файлами.

## 🛠 Технології
* Python 3.x
* Standard Libraries: `random`, `os`, `typing`
